# Gravity Tug: Color Clash

A 2-player local multiplayer Flutter MVP where each player taps targets on their side to pull a shared energy orb to their edge.

## Rules

- Player 1 (top/red): tap white circles to pull orb upward.
- Player 2 (bottom/blue): tap white circles to pull orb downward.
- Tapping a black circle (bomb) pushes the orb away from your side by a larger amount.
- First player to pull the orb fully to their edge wins.

## Run

```bash
flutter pub get
flutter run
```
